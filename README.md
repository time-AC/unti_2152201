Описание
Этот код представляет собой графическое приложение для поиска пользователей GitHub, написанное на Python с использованием библиотеки tkinter.Пользователь вводит логин, и программа отправляет запрос к API GitHub для получения данных о профиле.В списке выводится логин и имя найденного пользователя.Программа позволяет сохранять найденных пользователей в локальный файл favorites.json.Реализована проверка на дубликаты, чтобы один и тот же человек не попал в список дважды.
